# Architecture Decision Records

This service's decision log. Each ADR captures one significant decision as
**Context → Decision → Consequences**, following the process discipline
([`../process/adr-discipline.md`](../process/adr-discipline.md)); copy
[`../process/adr-template.md`](../process/adr-template.md) to `NNNN-title.md` (next
number) to start one.

New decisions get the next number; superseded ADRs are marked, not deleted. **Ask before
deviating** from any `Accepted` ADR — a deviation is its own new ADR.

Process-wide decisions (ones that bind every repo) live in the **process repo's** `adr/`,
not here; this log holds only what binds *this* repo.
