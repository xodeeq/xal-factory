_Date: 2026-09-20 · Branch: main · PR: pending (first commit)_

This repo was **born this session**, extracted from the author's private process repo with
every product-specific detail removed. This handoff is the entry point for future work here.

## What changed

- Repo created with `README.md`, `PRINCIPLES.md`, `CLAUDE.md`, `CONTRIBUTING.md`, `LICENSE`
  (MIT), `VERSION` (`0.1.0`).
- `spec/` — the service and deployment conventions rewritten without the reference-service
  citations; a new `gate-discipline.md` that gathers the gate rules previously scattered
  across script headers and context files; the ADR, concept-note and session-ritual
  documents generalized; the lifecycle guide marked informative.
- `sync/` — `process-sync.sh` (was `platform-sync.sh`), vendoring into `docs/process/` and
  pinning `PROCESS_VERSION`; the manifest gains `gate-discipline.md`.
- `scaffold/` — `common/` + `lang/go/` + `seed-service.sh`. The seeder gains `--module`;
  the Go overlay's CI checks this public repo out tokenless; credential rows and the
  project-board workflow are gone; the shared commands and skills moved out of the scaffold
  into the plugin and `common/.claude/settings.json` enables it (ADR-0003).
- `plugins/xal-process/` — `/begin-session`, `/wrap-session`, `concept-note`,
  `service-conventions`; `.claude-plugin/marketplace.json` publishes it.
- `scripts/check.sh` — eight gates. Gate 1's leak pattern is now a cross-language list and
  lives only in the script; the citation markers are `**Reference:**` / `<!-- reference -->`
  / a file-level `<!-- informative` marker; the link scan prunes `gates/fixtures/`.
- `gates/check.test.sh` + `gates/fixtures/check/` — **new**: one failing fixture per gate of
  this repo's own script plus a clean one. Previously only the seed gates had fixtures.
- `adr/` — four ADRs re-recorded generically: the sync model, seeding, the `.claude/`
  boundary, declared gate inputs.
- `docs/adopting.md` — the retrofit path for an existing repo.

## Decisions & lessons captured

- **What was stripped, and why:** the product catalogue, glossary and the domain ADRs
  (event envelope, async-first carve-outs, feed credential) are product architecture, not
  process. §7 of the service conventions keeps the generic rule — effects as versioned
  events, sync reads one hop deep and declared — and drops the product's specifics.
- **The board step stays, softened:** recording state outside the repo is a principle; the
  tool is the project's. The ritual now says "if the project keeps one".
- **The commands live in the plugin only.** The private scaffold shipped them twice (in
  `common/.claude/` and in a plugin). One home, per the duplication test in ADR-0003.
- **License:** MIT, chosen as the conventional default for process tooling. Change it before
  publishing if a different license is wanted.
- **Lesson, promoted:** the first run of `gates/check.test.sh` found gate 1 ending a
  paragraph-form citation at the first wrapped line, contrary to its documented rule. Fixed
  in the script; the clean fixture is the regression test. Recorded in `docs/lessons.md`.
